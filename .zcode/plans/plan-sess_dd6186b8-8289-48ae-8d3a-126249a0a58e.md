# ZCode Remote — Android App

## Context

ZCode is accessible remotely in a browser via `https://zcode.z.ai/remote/v4` — a client-rendered "Web Remote Control" SPA. The user wants an Android app with: (1) proper chat access, (2) easy device linking, (3) notifications when a chat is waiting for input or approval.

**How the remote works** (verified from the deployed JS bundle): the SPA connects to a relay over WebSocket (`wss://<relayOrigin>/ws/remote-control/window/<token>`) using `remoteControlToken` + `relayOrigin` (read from URL query params), bootstraps via `GET /api/remote-control/windows/bootstrap/<token>`, and the message protocol carries explicit states: `permission` / `permissionRequest` / `pendingApproval`, plus kinds `input`, `working`, `chunk`, `tool`. The SPA also ships a mobile-specific layout (`mobile-view-state`), so it renders well on phones.

## Architecture decision: Hybrid (WebView chat + native notifications)

- **Chat UI = WebView** hosting the real SPA. Full functionality day 1 (streaming chat, tool cards, diffs, approval dialogs), auto-updates with the web app, zero reverse-engineered protocol to maintain. The SPA's own login/flow works inside the WebView (cookies + DOM storage enabled).
- **Linking = native**: QR scan (ML Kit barcode + CameraX), paste-URL, Android share-target (links shared from Mac→phone open directly in the app), manual token entry. Parse `remoteControlToken` + `relayOrigin`, store encrypted.
- **Notifications = native foreground service + JS bridge**: inject a MutationObserver into the SPA that detects permission/approval/input prompts and calls a `@JavascriptInterface` bridge → service posts high-priority Android notifications, deduped per pending request, auto-cancelled on resolution. A dataSync foreground service keeps the process (and WebView JS) alive in background. (Fallback if DOM heuristics prove flaky during verification: v2 native WebSocket monitor — protocol is known but fragile to web updates.)

## Behavior details

- **Link screen** (shown when unlinked): big "Scan QR", "Paste link", "Enter token manually"; validates by parsing; on success → Chat.
- **Chat screen**: loads `https://zcode.z.ai/remote/v4?remoteControlToken=…&relayOrigin=…`; connection status banner; Material dark theme to match SPA.
- **Notifications**: "⚠️ Approval needed — <session/task snippet>", "💬 ZCode is waiting for your input"; tap opens app; re-notify only on new pending request; auto-dismiss when resolved (bridge reports both transitions).
- **Settings**: monitor on/off, start-on-boot toggle, disconnect/forget device, notification preferences.
